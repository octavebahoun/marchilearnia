Semestre 1 — les fondamentaux

01Maths de l'IA + NumPy / pandasAlgèbre linéaire, dérivées, probabilités›

Contenu

  • Vecteurs, matrices, produit matriciel, transposée
  • Dérivée, dérivée partielle, gradient — la notion centrale du deep learning
  • Probabilités, espérance, variance, loi normale
  • NumPy (broadcasting, vectorisation) et pandas (groupby, merge, pivot)

Ressources

  • YTMachine Learnia — playlists « Python spécial machine learning » et « Machine Learning » (les 10 premières vidéos couvrent le gradient)
  • YTMathrix — algèbre linéaire et probabilités, format court
  • YT3Blue1Brown (sous-titres FR) — série « Essence of linear algebra », la meilleure intuition visuelle qui existe
  • DataCampIntroduction to Statistics in Python · Data Manipulation with pandas
  • KagglePandas (micro-cours)
Livrable : un notebook où tu implémentes une descente de gradient en NumPy pur sur une régression linéaire, avec la courbe de perte tracée.
02Machine learning classiquescikit-learn, métriques, validation›

Contenu

  • Régression linéaire et logistique, k-NN, SVM
  • Arbres, random forest, gradient boosting (XGBoost, LightGBM)
  • Train/test, validation croisée, surapprentissage
  • Métriques : accuracy, précision, rappel, F1, ROC-AUC, RMSE
  • Feature engineering et pipelines sklearn

Ressources

  • YTMachine Learnia — suite de la playlist « Machine Learning » (sklearn en détail)
  • YTScience4All — vidéos sur le biais/variance et la théorie de l'apprentissage
  • DataCampSupervised Learning with scikit-learn · Machine Learning with Tree-Based Models
  • KaggleIntro to Machine Learning · Intermediate Machine Learning · Feature Engineering
Livrable : une compétition Kaggle « Getting Started » terminée, soumission faite, notebook commenté en français.
03Deep learning depuis zéroPerceptron, backpropagation, à la main›

Contenu

  • Neurone, fonctions d'activation, couches
  • Propagation avant, fonction de coût, rétropropagation
  • Descente de gradient stochastique, mini-batch, learning rate
  • Régularisation : dropout, batch norm, early stopping
  • Lire une architecture de modèle et comprendre ce qu'elle fait

Ressources

  • YTMachine Learnia — playlist « Deep Learning », réseau de neurones codé from scratch
  • YTThibault Neveu — deep learning expliqué en français, orienté intuition
  • YTAndrej Karpathy — « Neural Networks: Zero to Hero » (anglais, sous-titres auto). Fais au moins micrograd, ça vaut la semaine à lui seul.
  • DataCampIntroduction to Deep Learning in Python
Livrable : un réseau à 2 couches cachées codé sans framework, entraîné sur MNIST, précision affichée.
04PyTorch, TensorFlow, Hugging FaceLes librairies du module de 63h›

Contenu

  • Tenseurs, autograd, nn.Module, DataLoader
  • Boucle d'entraînement écrite à la main en PyTorch
  • Keras/TensorFlow pour comparer les deux approches
  • Hugging Face : pipelines, from_pretrained, datasets, fine-tuning léger
  • Entraînement sur GPU Colab, sauvegarde et rechargement de poids

Ressources

  • DataCampIntroduction to Deep Learning with PyTorch · Intermediate Deep Learning with PyTorch
  • DocCours Hugging Face — chapitres 1 à 3, traduits en français sur huggingface.co/learn
  • YTDefend Intelligence — vidéos PyTorch et modèles pré-entraînés
  • KaggleIntro to Deep Learning
Livrable : le même MNIST de la semaine 3, réécrit en PyTorch, puis en Keras. Tu compares le code et les temps.
05Vision par ordinateurCNN, transfer learning, YOLO, OCR›

Contenu

  • Traitement d'image classique : filtres, seuillage, contours (OpenCV)
  • Convolution, pooling, architectures CNN (VGG, ResNet)
  • Transfer learning et fine-tuning sur un petit dataset
  • Détection d'objets avec YOLO (Ultralytics), annotation avec Roboflow
  • OCR avec Tesseract ou PaddleOCR

Ressources

  • YTMachine Learnia — vidéos CNN et vision
  • YTThibault Neveu — détection d'objets et applications
  • DataCampImage Processing in Python · Deep Learning for Images with PyTorch
  • KaggleComputer Vision
  • DocDocumentation Ultralytics YOLO — quickstart et entraînement custom
Livrable : un détecteur entraîné sur tes propres photos annotées. Prends des devantures de boutiques — ça alimente directement ta cartographie du marché PK3.
06NLP, d'avant les LLM jusqu'aux transformersLe module de 49h suit exactement cette progression›

Contenu

  • Histoire de l'IA depuis les années 50 : symbolique, hivers de l'IA, connexionnisme
  • NLP pré-LLM : tokenisation, stemming, sac de mots, TF-IDF, n-grammes
  • Word2Vec, GloVe, embeddings
  • RNN, LSTM, mécanisme d'attention
  • Transformers : « Attention is all you need », BERT vs GPT, fine-tuning

Ressources

  • YTScience4All — série sur l'histoire de l'IA et le fonctionnement des LLM
  • YTScienceEtonnante — vidéo sur GPT et les modèles de langage
  • DocCours Hugging Face NLP — chapitres 4 à 7 (fine-tuning, tokenizers)
  • DataCampIntroduction to NLP in Python · Introduction to LLMs in Python
  • KaggleNatural Language Processing
Livrable : un classifieur de texte fait deux fois — version TF-IDF + régression logistique, version BERT fine-tuné. Tu écris 10 lignes sur l'écart de performance et de coût.
